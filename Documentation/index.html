Installation

Upload the contents of the HTML folder to your server. No build step is needed to use the template.

├── scss/

CSS / SCSS

Colors, fonts and spacing live in scss/abstracts/_variables.scss. To recompile:

npm install
npm run build   # or: npm run watch

JavaScript

assets/js/main.js handles the mobile menu and active link highlighting.
